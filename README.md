# Drone Cam

Android-застосунок для перегляду камери борту з телефону в тій самій мережі Wi-Fi.

## Встановлення
Завантажте `DroneCam.apk` з [останнього релізу](https://github.com/CrazySharkxo/drone-cam-android/releases/latest)
і встановіть (Android 7+; потрібно дозволити встановлення з цього джерела).

Далі застосунок оновлюється сам: при запуску перевіряє новий реліз і пропонує оновитися.
Кнопка «Перевірити оновлення» — на головному екрані.

Тут лежать лише релізи з APK.
